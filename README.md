# TelemetryMod

A Factorio 2.0 telemetry mod with independently configurable JSONL, local UDP and RCON outputs. See [the mod README](mod/telemetry-mod/README.md) for installation and settings and [integration examples](examples/README.md) for Discord and OBS.
