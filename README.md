# TelemetryMod

A Factorio 2.1 telemetry mod with independently configurable JSONL, local UDP and RCON outputs. See [the mod README](mod/telemetry-mod/README.md) for installation and settings and [integration examples](examples/README.md) for Discord and OBS. For Factorio 2.0, use Telemetry Mod 0.2.0.
